# Лототрон — сайт конкурса-лотереи

Статичный сайт: `index.html`, `style.css`, `config.js`, папка `js/`, `demo.csv`. Сервер не нужен — подойдёт любой хостинг статичных файлов (GitHub Pages, домен компании).

## Таблица (для Ярика)

Один лист Google-таблицы. Пример — `шаблон-таблицы.csv` в корне проекта (Файл → Импорт).

| ФИО | Город/салон | Направление | ПДС, ₽ |
|---|---|---|---|
| Смирнова Анна Сергеевна | Брянск | Корпус | 2 553 000 |

- **ПДС, ₽** — сумма принятых денежных средств **накопительно с 19 ноября**, в рублях. Купоны сайт считает сам: 1 купон за каждые 200 000 ₽.
- **Обновлено** — над шапкой можно оставить строку «Обновлено | 27.11.2026», дата появится на сайте.
- Порядок колонок не важен, важны начала названий: «ФИО», «Город», «Направ…», «ПДС».
- Пустые строки и строки без ФИО пропускаются.
- Не меняй ФИО и город у человека посреди конкурса: по ним сайт узнаёт его на телефоне.

**Публикация (один раз):** Файл → Поделиться → Опубликовать в интернете → выбрать лист → «Значения, разделённые запятыми (.csv)» → Опубликовать. Скопировать ссылку и вставить в `config.js` в `CSV_URL`.
После этого достаточно просто править таблицу: сайт берёт свежие данные при каждом открытии (Google обновляет опубликованную копию с задержкой до 5 минут).

## Как это выглядит для продавца

- Первый заход: ввести 3+ буквы фамилии → выбрать себя. Телефон запоминает выбор.
- Каждый следующий заход: если купонов стало больше — новые падают в барабан с конфетти.
- «Это не я» внизу карточки — выбрать заново.
- Ссылка `…/?id=xxxxxx` открывает конкретного человека (id виден в адресе после выбора).

## Приватность

Страница открывается без пароля. Поэтому полный список ФИО нигде не показывается: в рейтинге — «Анна С., Брянск», в поиске — только совпадения после 3 букв фамилии. Страница закрыта от поисковиков (`noindex`).

## Проверка у себя

```bash
python3 -m http.server 8765 --directory site
```
Открыть http://localhost:8765. Тесты логики: `node --test tests/`.

## Переезд на домен компании

Скопировать содержимое папки `site/` на сервер как есть. Больше ничего не нужно.
